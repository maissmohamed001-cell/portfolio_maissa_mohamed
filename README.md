# Mohamed Maissa | Full Stack Developer Portfolio

## 🎯 Project Overview
A fully responsive, interactive portfolio website showcasing my skills as a Full Stack Developer with focus on modern web development (HTML, CSS, JavaScript).

## ✨ Key Features
- **Responsive Design** - Mobile-first approach (Desktop, Tablet, Mobile)
- **Interactive Navigation** - Smooth scrolling with active link highlighting
- **Contact Form** - Fully validated form with success popup
- **Skills Section** - Three specialized skill categories with hover effects
- **Mobile Menu** - Hamburger navigation for smaller screens
- **Accessibility** - ARIA labels, keyboard navigation (Ctrl+K to focus form, Esc to close)
- **Smooth Animations** - Intersection Observer for scroll animations
- **Dark Theme** - Modern dark aesthetic with orange/teal accent colors

## 🛠 Technologies Used
- **HTML5** - Semantic markup
- **CSS3** - Flexbox, Grid, animations, gradients, responsive design
- **JavaScript (Vanilla)** - ES6+ classes, event handling, form validation
- **No Framework** - Pure JavaScript for maximum learning value

## 📖 Key JavaScript Classes

### MobileMenuManager
Handles mobile navigation toggle with ARIA support

### FormValidator
- Email validation with regex
- Real-time field validation
- Success popup on submission
- Error state management

### NavigationManager
- Active link highlighting on scroll
- Smooth navigation between sections

### ScrollToTopManager
- Fixed button appears after 300px scroll
- Smooth scroll animation

### HeaderScrollEffect
- Header styling changes on scroll

### ScrollAnimationManager
- Intersection Observer for fade-in animations

## 🔧 Features in Detail

### Form Validation
- Name: minimum 2 characters
- Email: valid email format
- Subject: minimum 3 characters
- Message: minimum 10 characters
- Real-time validation feedback
- Displays error messages inline

### Keyboard Shortcuts
- **Ctrl+K** - Focus on contact form name field
- **Esc** - Close mobile menu & thank you popup

### Accessibility
- Semantic HTML (`<header>`, `<main>`, `<footer>`)
- ARIA labels on all interactive elements
- Keyboard navigation support
- Color contrast compliant
- Skip links available
